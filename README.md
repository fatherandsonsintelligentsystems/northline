# Northline

Luxury chauffeur booking for Niagara Falls, casino nights, and GTA / airport transfers.

Built with TanStack Start, Vite, React, and Tailwind. Designed to deploy on Vercel.

## Local development

```bash
npm install
npm run dev
```

App runs at `http://localhost:8080`.

## Production build

```bash
npm run build
```

Vercel is linked to this repository. Pushes to `main` auto-deploy.

## Stack

- TanStack Start + React Router
- Tailwind CSS 4
- Kysely + PGlite (local) / Postgres-ready migrations
- Better Auth
